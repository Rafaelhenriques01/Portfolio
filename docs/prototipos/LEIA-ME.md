# Protótipos (Figma)

Exporte as telas do Figma em PNG e salve **nesta pasta** com exatamente estes nomes,
para que as imagens apareçam no README principal:

| Arquivo                  | Tela do protótipo                       |
| ------------------------ | --------------------------------------- |
| `01-sobre-mim.png`       | Sobre Mim (hero com foto e botão)       |
| `02-projetos.png`        | Projetos (linha do tempo)               |
| `03-projeto-detalhe.png` | Detalhe do projeto (imagem/GIF + GitHub)|
| `04-experiencias.png`    | Experiências (cards)                    |
| `05-contato.png`         | Contato (formulário + ícones)           |

**Como exportar no Figma:** selecione o frame → painel direito → *Export* → formato `PNG` → `2x` → *Export*.

Link do arquivo no Figma: https://www.figma.com/design/e4Malif4A6em6Vo9LXrWvZ/Wireframes-portfolio?node-id=0-1
